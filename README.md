# AirSend

Laravel and Django services for AirSend.

## Run locally

Run `run.bat` on Windows or `run.command` on macOS. The launcher installs missing dependencies, then starts Laravel at `http://127.0.0.1:8070` and Django at `http://127.0.0.1:3075`.

## Prerequisites

PHP, Composer, Node.js LTS, and Python 3. The first run may take longer while Composer installs the Laravel dependencies.
